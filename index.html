01｜新人先看

任何臨床工作先照這個順序

1

確認新病人或舊病人

新病人使用標準 Admission Template；舊病人先拿上一份 Admission Note。

2

確認本次最新資料

本次最新 SOP / Regimen / Order / Workflow ＞ Knowledge ＞ Previous Plan ＞ 一般醫療知識。

3

完成必要資料核對

診斷、Regimen、Course、日期、BSA、體重、禁治療側、Port、Denosumab、Zoladex、內分泌治療。

4

做 discrepancy check

Admission Plan 與實際 Order 不一致時明確標示，交由醫療人員確認。

新人常見錯誤

  • 舊病人重新建立整份 Plan，導致前後格式不一致
  • 把 Order Library 內容直接塞入 Admission Note
  • 看到熟悉藥物就自行修正院內資料
  • 只寫 G-CSF Day 3 / Day 4，未換算實際日期
  • 漏核對禁治療側、Course、Port、日期、輸注方式

06｜Endoscopic Simple Mastectomy + SLNB

手術區快速 SOP

術前 Mark / 拍照 / 消毒 / 擺位
  • 站立時完成 mark：IMF、sternal notch、水平線、breast 內側
  • 站立拍照，背景綠單
  • chlorhexidine 消毒，腋下有毛需除毛
  • 雙側乳房消毒，消毒後重新畫清楚 mark
  • 病人放最邊邊，單側墊脂肪墊，術中手臂可能調整開合
器械與材料準備
  • Jelly + methylblue，無菌混合
  • Tumescent：1000cc N/S + 20cc lidocaine + 1cc epinephrine
  • 側孔鈍頭抽脂金屬管、點滴加壓器、大 kupa 剪刀、深鉤
  • Glove port（病人自費），gas 約 8
  • 電燒 spoon / hook、30° scope
  • 無菌塑膠量筒、implant sizer、funnel
  • 縫線：4-0 Vicryl、Monocryl 4-0；表皮 Liquiband
Mastectomy / Tumescent / Hydrodissection
  • 傷口約 5 cm，側胸腋中線或腋下
  • 先做 pre-muscle plane，不打 tumescent
  • sub nipple frozen 優先送術中
  • superficial plane 前打 tumescent，hydrodissection 後以大 kupa 剪刀分離
  • open 視野不足後換 gas endoscopy
Specimen / SLNB
  • breast tissue 取出後立即定位：12 點兩線、3 點一線
  • Table 下測量體積與重量；原始資料註記密度 0.9
  • 同一傷口完成 SLNB；影像原本有淋巴轉移需送 frozen
  • 術中使用放射線 navigator
  • 若 SLNB positive：改 second stage reconstruction，先 tissue expander
Reconstruction / Implant placement / Post-op
  • Dual plane，內視鏡分開胸大肌下緣；以尺量 breast width，使用 sizer 並讓病人術中坐起
  • 引流管一條，由腋下出來；完全確認止血後決定 implant
  • 放 implant 前清潔病人並換手套
  • Antibiotic irrigation：1000cc NS + 1g Cefa + 80mg Genta
  • 若使用 funnel：原始 SOP 特別註記「不要剪開，我來剪」
  • 甦醒前穿術後衣與定位衣；乳頭血循恢復期間胸前釦子解開，乳頭不可加壓

08｜資料優先順序與安全規則

遇到不確定時，以這裡為準

資料優先順序

  1. 本次最新提供的 SOP / Regimen / Order / Workflow
  2. Knowledge Database 的院內文件
  3. 既有 Admission Note / Previous Plan
  4. 一般醫療知識

兩份院內文件互相衝突時，優先日期較新或使用者明確指定版本；無法判斷則要求確認。

所有輸出都是 DRAFT

  • 不得宣稱已正式開立醫囑
  • 不得自行判定健保／事前審查已核准
  • 不得自行判定特定藥物一定適用
  • 不得自行判定病人一定可以接受治療
  • 不得自行判定特定劑量一定正確
  • Plan 與 Order 不一致時要明確標示 discrepancy

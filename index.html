01｜新人先看

碰到任何臨床工作，先照這個順序

1

確認這次是新病人還是舊病人

新病人用標準 Admission Template；舊病人先拿上一份 Admission Note。

2

確認本次最新版資料

本次最新 SOP / Regimen / Order / Workflow 優先，再看 Knowledge Database。

3

完成資料核對才建立草稿

診斷、Regimen、Course、日期、BSA、禁治療側、Port、骨轉移或內分泌治療等。

4

最後做 discrepancy check

Admission Plan 與實際 Order 不一致時，明確標示並要求確認。

新人最容易犯的錯

  • 舊病人重新打一整份 Plan，造成格式與內容前後不一致。
  • 看到熟悉藥物就用一般醫療知識「自動修正」院內資料。
  • 把 Order Library 的內容直接塞進 Admission Note。
  • 只寫 Day 3 / Day 4，沒有換算 G-CSF 的實際注射日期。
  • 未再次核對禁治療側、Port、Course、日期、劑量與輸注方式。

02｜新病人 vs 舊病人

這是整個工作流程的第一個分岔點

NEW PATIENT

新病人

使用標準 Admission Template，不從零開始自由撰寫。

  • 診斷
  • Regimen / Course / 化療日期
  • BSA（必要時計算）與體重
  • 禁治療側
  • 是否有 Port
  • 是否需要 Denosumab / Zoladex
  • 是否持續 AI、Tamoxifen 等內分泌治療

資料確認後再依對應 Regimen 產生 Admission Plan 草稿。

RETURNING PATIENT

舊病人

第一步不是重做，而是先拿到上一份 Admission Note。

  • 沿用既有 Plan 與格式
  • 更新 Course
  • 更新日期
  • 更新 BSA / 劑量
  • 更新檢查結果
  • 更新臨床狀況

原則：盡量維持病歷格式與內容一致性。

04｜Order Library 與醫囑核對

Order Library 是核對工具，不是 Admission Note 內容

Order Library 何時使用

只有在需要「開立醫囑草稿、檢查醫囑、列出今日 Orders、核對醫令」時使用。

每筆 Order 要保存

醫令代碼、藥名、劑量、給藥途徑、頻率、Instruction、備註、所屬 Regimen。

院內代碼前綴

O＝口服 PO
I＝注射 IV / IVD / SC / IM
T＝外用藥

可用來檢查格式是否合理，但不能直接判定醫囑正確。

化療醫囑建立時的指定套餐
  • T-DXd：[Palliative] T-DXd (Trastuzumab Deruxtecan)
  • Lipodox + Cyclophosphamide：[Neoadjuvant] EC (Lipodox)
  • Sacituzumab govitecan：[Palliative] Sacituzumab govitecan
  • Pembrolizumab + Paclitaxel + Carboplatin：分別建立三個套餐

完成後再次確認所有藥物、劑量、輸注速度、內容是否與 Admission Plan 一致，再正式開立醫囑。

G-CSF 核對

現有 Knowledge：ILEN2 = Lenograstim；文件記錄為 G-CSF 1 vial (250 mcg/vial) SC for 2 days after chemotherapy, day 3 and day 4。

需依化療日期換算實際注射日期，並確認是否遺漏、醫令代碼是否正確、注射日期是否一致。

06｜Endoscopic Simple Mastectomy + SLNB

手術助手快速流程版

流程時間線

1. 材料與器械

Jelly + methylblue、tumescent solution、鈍頭抽脂金屬管、加壓器、大 kupa 剪刀、深鉤、glove port、30° scope、sizer、funnel、沖洗液與縫線。

2. Mark / 拍照 / 消毒 / 擺位

站立先畫 IMF、sternal notch、水平線、breast 內側；綠單背景拍照；chlorhexidine；雙側乳房消毒；必要時腋下除毛。

3. Mastectomy

側胸腋中線或腋下約 5 cm；先 pre-muscle plane，再 simple；送 sub-nipple frozen；後續視野不足再轉 gas endoscopy。

4. Tumescent / Hydrodissection

完成 superficial plane；以鈍頭側孔金屬管進水剝離，再以大 kupa 剪刀分離，放 glove port，兩支器械＋30° scope。

5. Specimen / SLNB

breast tissue 取出後立即定位；同一傷口完成 SLNB。影像原已有淋巴轉移者送 frozen。

6. Reconstruction / Implant

Dual plane、sizer、術中坐起評估、單條引流從腋下出、確認止血，再進 implant。

7. Closure / Post-op

4-0 Vicryl、Monocryl 4-0、Liquiband；甦醒前穿術後衣；乳頭避免加壓。

手術室高優先注意

  • 乳頭循環：術後衣胸前釦子解開，乳頭不要加壓。
  • Breast specimen：取出後馬上定位，12 點兩線、3 點一線。
  • SLNB positive：原 SOP 記錄改為 second stage reconstruction，先用 tissue expander。
  • 放 implant 前：清潔、換手套、沖洗、完全確認止血。
  • Funnel：原始文件特別註記「不要剪開，我來剪」。

08｜健保／贈藥／行政

只協助整理，不自行判定資格或核准狀態

健保／事前審查

優先依院內事前審查流程；若 Plan 已註記 self pay，依自費流程整理。不可自行判定已核准或符合給付資格。

贈藥／庫存

即時庫存查詢路徑：warehouse → 藥劑科 → 即時庫存查詢。

廠商贈藥

原 Knowledge：聯絡藥局 266161；自備藥自服使用 OPTSELF，並寫在註釋。

09｜安全規則總表

這一區是最後一道防線

不得自行做的事

  • 宣稱已正式開立醫囑
  • 判定健保已核准／事前審查已通過
  • 判定某藥物一定適用
  • 判定病人一定可以接受治療
  • 判定某個劑量一定正確
  • 用一般醫療知識偷偷改掉院內 SOP

發現 discrepancy 時

Admission Plan、Regimen、Order、護理指示或健保流程互相不一致時：

  1. 明確標示不一致位置
  2. 列出目前看到的兩個版本
  3. 優先採用較新或被明確指定的院內文件
  4. 無法判斷時，不自行選答案，交由醫療人員確認
